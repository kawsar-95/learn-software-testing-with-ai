## Page outline
- ## What a permission mode is — C1, C2. One table: mode, what runs without asking, best for (S1 table). QA angle: pick the mode by risk of the task (reading a test log vs editing a test suite vs running against a shared DB).
- ## The six modes
  - ### Manual (`default`) — C3
  - ### `acceptEdits` — C4, C23, C24; QA use: iterate on test files, review with `git diff`
  - ### `plan` — C5, C6, C25; QA use: requirement analysis, test design review, unfamiliar codebase
  - ### `auto` — C7, C26-C29; callout C27
  - ### `dontAsk` — C8, C30, C31; QA use: CI test runs
  - ### `bypassPermissions` — C9, C33-C38; danger callout
