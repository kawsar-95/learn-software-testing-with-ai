## Page outline
- ## Lede — a prompt is the instruction; in Claude Code the check you give is part of it (C6).
- ## Write specific prompts — the four moves and before/after table (C1 to C5, C29, C42). Add a one-line "colleague test" (C32).
  - ### A prompt checklist for QA — Context, Scope, Constraints, Verification, optional Role (see Old content). Own framing; cite S1/S3 per row.
- ## Give Claude a way to verify its work — pass/fail check; evidence; `/goal`, Stop hook, subagent reviewer, `/verify` (C6 to C13, C39, C40). QA: "tests pass" must be real: add C37 as a callout (test-gaming).
- ## Point Claude at your material — `@file`, `@dir`, `@server:resource`, images, URLs, pipes, CLI tools (C14 to C18). Limits: 25,000 tokens, 256KB (C15). QA: failing log, screenshot, ticket via MCP.
- ## Explore, then plan, then code — plan mode keys and flags; what plan mode can do; `Ctrl+G`; when to skip (C19 to C25).
- ## Examples for QA tasks (the page's own prompts built from the cited patterns; each ends with a verification clause)
  - ### Requirement review — e.g. "Read @docs/requirements/payments.md. List ambiguities, missing acceptance criteria, and untestable statements. Ask me questions with the AskUserQuestion tool before you write anything. Do not write test cases yet." (C25, C19). Link to Test Design page for the next step.
  - ### Bug reproduction — e.g. "Users report checkout fails after the session times out. The code is in src/auth/. Write a failing Playwright test that reproduces it. Run it and show me the failing output. Do not fix the bug yet." (C4, C11, C28).
  - ### Test generation — e.g. "Read @src/payments/discount.ts and the existing tests in tests/payments/. Add tests in the same style for the edge cases we do not cover. Run them and show the results. Do not change production code." (C26, C27, C37).
  - ### Root cause from a log — `cat error.log | claude -p "…"` or `@error.log` (C17, C38).
- ## Keep the conversation healthy — `Esc`, `/clear` after two failed corrections, scope investigations, subagents (C30, C31, C41). Link to How Claude Code Works for context and compaction.
