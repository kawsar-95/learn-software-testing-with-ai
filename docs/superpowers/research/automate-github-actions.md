## Open questions
- S3 says "beta" while S1/S5 show v1 (latest). Writer should not label the action beta.
- Tool pattern syntax: S1/S9 use `Bash(git diff *)` (space-star); the repo S4 example uses the colon form `Bash(gh issue view:*)`. Use the space-star form (documented in S1/S9) in examples.
- The year of the v1.0.24x release dates was not shown on the releases page; do not state dates.
- Claude Code GitHub Actions model examples in docs: `claude-sonnet-5`, `claude-opus-5-5` (S1); the repo example uses older IDs (S6). Prefer omitting `--model` or follow the Models page.
- Composed QA workflow YAML (tests review, write tests) is not copied from a source; it combines documented inputs and must be labeled as an example.
- `docs/setup.md` (custom GitHub App) and the Code Review page were not fetched.
