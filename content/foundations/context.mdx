# Context Engineering

## Definition

Designing what information the AI sees, not just how you ask.

### ✅ What it focuses on:

- Supplying relevant data dynamically
- Using RAG (Retrieval-Augmented Generation)
- Feeding: Codebase chunks, Jira tickets, Logs, DB data, Commit history

### 💡 Example:

**Instead of:**

```text
Explain this error
```

**You do:**

```text
Context:
- API endpoint: /user/login
- Stack trace: ...
- Related code: (retrieved from vector DB / Attached File)
- Last commits: ...

Task: Analyze root cause
```

## Prompt Engineering vs Context Engineering

| Aspect | Prompt Engineering | Context Engineering |
|---|---|---|
| Focus | How you ask | What AI knows |
| Power | Limited | Massive |
| Accuracy | Medium | High |
| Scalability | Poor | Excellent |
| Use Case | Simple Q&A | Real systems |
| Dependency | Prompt wording | Data quality |
